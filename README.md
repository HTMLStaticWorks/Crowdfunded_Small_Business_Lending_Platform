# LendCircle — Crowdfunded Small Business Lending Platform

Frontend-only multi-page website concept.

Pages:
index.html, home-2.html, borrow.html, invest.html, how-it-works.html,
success-stories.html, about.html, contact.html, login.html, signup.html,
dashboard.html

Assets:
assets/css/style.css
assets/js/main.js

Built with HTML5, CSS3, Vanilla JavaScript and Bootstrap 5 CDN.
Includes responsive layout, SEO metadata, RTL toggle, light/dark theme,
login/signup pages, borrower/lender dashboard views, four-column footer,
favicon/logo and scroll-to-top control.

All financial data and interactions are fictional demo content.
